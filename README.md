THE HUMAN FIREWALL
Your Mind Is Your First Line of Defence.

1. Project Overview
The Human Firewall is a cybersecurity awareness project focused on educating students and internet users about phishing attacks and online safety.

The project explains how phishing works, how to recognise suspicious messages and how individuals can protect their personal information.

 2. Project Objectives
- Raise awareness about phishing attacks.
- Help users identify suspicious emails and messages.
- Encourage safe online behaviour.
- Promote responsible use of digital platforms.

 3. Project Contents
 File Description 
 phishing-awareness-guide.md  Provides information about phishing, warning signs and prevention methods. 
 README.md  Introduces the project and explains its purpose. 

 4. Target Audience
Students, university communities and everyday internet users.

5. Cybersecurity Practices
- Use strong and unique passwords.
- Enable two-factor authentication.
- Avoid suspicious links and attachments.
- Verify information before sharing it.
- Report suspected phishing attempts.

 6. Tools Used
- GitHub for project hosting and version control.
- Markdown for creating and documenting project files.

 7. Conclusion
